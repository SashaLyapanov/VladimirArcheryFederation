# Сценарии использования

## Роли пользователей

### 1. Неавторизованный пользователь
- просмотр информации об организации
- просмотр новостей
- просмотр соревнований
- регистрация

### 2. Спортсмен
- вход в систему
- редактирование профиля
- подача заявки на соревнование
- просмотр результатов

### 3. Администратор
- создание и редактирование соревнований
- изменение статусов соревнований
- управление пользователями
- публикация новостей
- управление документами

### 4. Судья
- выбор соревнования в статусе проведения
- генерация Excel-протокола
- загрузка заполненного файла
- последовательная обработка этапов
- генерация итогового PDF

## Ключевые пользовательские сценарии

### Регистрация пользователя
1. Пользователь открывает форму регистрации.
2. Заполняет данные.
3. Получает письмо для подтверждения email.
4. После подтверждения аккаунт становится активным.

### Подача заявки на соревнование
1. Спортсмен авторизуется.
2. Открывает страницу соревнования.
3. Заполняет форму регистрации.
4. Система сохраняет заявку.

### Проведение соревнования
1. Судья открывает нужное соревнование.
2. Генерирует Excel-протокол.
3. Вносит результаты.
4. Загружает файл обратно в систему.
5. Система обрабатывает этапы соревнования.
6. Генерируется итоговый PDF-протокол.
