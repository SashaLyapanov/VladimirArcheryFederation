# Обзор проекта

## Назначение системы

Программно-информационная система предназначена для автоматизации
деятельности спортивной федерации стрельбы из лука.

Система решает следующие задачи:
- автоматизация регистрации пользователей
- управление соревнованиями
- регистрация спортсменов на мероприятия
- ведение новостей и документов
- автоматизация обработки результатов соревнований

## Проблема

До внедрения системы значительная часть процессов выполнялась вручную:
- хранение информации в бумажном виде и локальных файлах
- ручная обработка заявок
- ручное формирование протоколов
- повышенная зависимость от человеческого фактора

## Цель проекта

Создать web-приложение, которое автоматизирует управленческие и
производственные процессы внутри организации, а также упрощает
взаимодействие федерации с заинтересованными лицами.

## Ключевые особенности

- ролевая модель пользователей
- автоматизация соревновательного процесса
- работа с Excel-протоколами
- генерация PDF-документов
- хранение и управление файлами
- клиент-серверная архитектура
