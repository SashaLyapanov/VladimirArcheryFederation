# База данных

## Используемая СУБД

В проекте используется PostgreSQL.

Причины выбора:
- реляционная модель
- надежность
- транзакционность
- бесплатная лицензия
- высокая производительность
- совместимость с Java ecosystem

## Управление схемой

Для миграций используется Liquibase.

Это позволяет:
- хранить изменения схемы в репозитории
- воспроизводимо поднимать проект
- версионировать структуру БД

## Основные сущности

- users
- sportsmen
- admins
- judges
- competitions
- applications
- protocols
- news
- documents

## Особенности модели

- используется ролевая модель пользователей
- логика соревнований завязана на этапы и протоколы
- хранение промежуточных и итоговых результатов вынесено в отдельные сущности
- работа с пользователями организована через наследование сущностей
